# Godmode Lite — Free Execution Protocol for Claude Code

One command transforms Claude Code from a helpful assistant into a relentless engineering machine. Godmode Lite gives you 4 core execution layers for free.

## What it does

When you type `godmode lite` before any task, Claude Code activates:

1. **Deep Context Load** — Reads every related file, not just the ones it needs
2. **Complete Execution** — Every edge case handled, every input validated, no stubs
3. **Exhaustive Testing** — Unit tests, failure paths, integration tests, full suite runs
4. **Polish** — No dead code, specific types, helpful errors, production-ready

## Install (30 seconds)

mkdir -p ~/.claude/skills/godmode-lite

## Usage

Type any of these before your task in Claude Code:

```
godmode lite: build a REST API with auth
gm lite: refactor this module with full test coverage
try godmode: audit this codebase and fix every issue
```
